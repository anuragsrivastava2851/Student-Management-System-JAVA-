# Student Management System (Java) 🌱 My First Java Project

A simple console-based Student Management System — my very first project in Java, built to practice core concepts like classes, objects, switch-case logic, and basic input handling.

## Features

- Add a student (Roll No, Name, Age, Course)
- View all students
- Search a student by Roll No
- Update a student's details
- Delete a student
- Exit the program

## Project Structure

```
Student-Management-System-JAVA/
│
├── src/
│   ├── Main.java             # Entry point — menu and user input handling
│   ├── Student.java          # Student model class
│   └── StudentService.java   # Business logic for add/view/search/update/delete
```

## Tech Stack

- Java
- `java.util.Scanner` for console input

## How to Run

```bash
cd src
javac Main.java Student.java StudentService.java
java Main
```

## What I Learned

This project was built to get hands-on with:
- Object-oriented programming basics (classes, objects, encapsulation)
- Switch-case driven menu systems
- Handling user input and basic validation (e.g. invalid age, invalid menu choice)
- Structuring a small Java application across multiple files
